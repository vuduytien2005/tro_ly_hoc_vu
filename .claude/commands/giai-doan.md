Đọc CLAUDE.md và docs/07-ke-hoach-va-prompt.md.
Tìm mục "Giai đoạn $ARGUMENTS", đọc các tài liệu mà mục đó yêu cầu, rồi:
1. Tóm tắt mục tiêu giai đoạn và kiểm tra các giai đoạn trước đã hoàn thành chưa (xem code hiện có). Nếu chưa, báo tôi.
2. Đề xuất kế hoạch chi tiết (danh sách file sẽ tạo/sửa, thứ tự làm) và CHỜ tôi đồng ý.
3. Thực hiện, chạy test.
4. Kết thúc bằng: danh sách file đã tạo/sửa, cách tôi tự kiểm tra, đối chiếu "Tiêu chí hoàn thành", và gợi ý commit message.
Giải thích bằng tiếng Việt.
